# Snake Game

A classic Snake Game implemented in HTML5, CSS, and JavaScript. Play directly in your browser!

## Features
- Adjustable speed (느림, 보통, 빠름, 매우 빠름)
- Score tracking and local ranking (Top 3)
- Simple and clean UI
- Responsive controls (Arrow keys)

## How to Play
- Use the arrow keys to control the snake.
- Eat the red food blocks to grow and increase your score.
- Avoid colliding with the walls or your own body.
- Click the "Restart" button to play again.

   ```bash
   git clone https://github.com/madambean/snake-game.git
   ```
2. Open `index.html` in your browser.
